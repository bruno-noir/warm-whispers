# Warm Whispers

**Where every flame tells a story.**

A website for a scented candle brand, built as a college project.

**Live site:** https://bruno-noir.github.io/warm-whispers/

## About

Warm Whispers sells beautifully designed scented candles in hand painted tins.
The site presents five fragrances (Rose, Lavender, Vanilla, Coffee and
Sandalwood) across thirteen sections, from the hero through to an order form.

## Built with

Plain HTML, CSS and JavaScript. No frameworks, no build step, no dependencies.
Open `index.html` in any browser and it runs.

| File | Purpose |
| --- | --- |
| `index.html` | All thirteen sections of the page |
| `styles.css` | Styling, organised into 24 numbered blocks |
| `script.js` | Interactive behaviour, in 10 numbered blocks |
| `assets/` | Product and gallery photography |
| `warm-whispers-live.html` | Single self-contained copy with everything embedded |

## Features

- Responsive layout for phone, tablet and desktop
- Sticky navigation with a mobile menu
- Add to cart with a counter that persists between visits
- Shop by Mood, which jumps to and highlights the matching candle
- Filterable gallery with a lightbox
- FAQ accordion
- Order form with full client side validation

The cart and order form are demonstrations. No real order is placed.
